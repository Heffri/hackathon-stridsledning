`team-missile-intercept/` is the only active project in this repo

post-Finale shipping snapshot. Older state lives on the
`archive/*` branches.

## Active Project

`team-missile-intercept/` contains the 3D AI-vs-AI missile-intercept
sandbox. Red AI launches threats (drones, cruise missiles,
ballistic missiles, HGVs); Blue AI selects interceptors and
computes real-time intercept solutions. Multiple Blue and Red
policies (rule-based + RL-trained) are loadable from the SETUP
dropdown.
