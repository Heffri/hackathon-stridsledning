# Archive

This folder holds frozen historical material that is no longer the active
runtime or default documentation home for the repo.

## Current Archive Contents

- `xingyi-rts` legacy project tree kept for provenance and traceability

## Rules

- Do not add new active gameplay logic here.
- Do not point the active runtime back into `archive/`.
- If archived material is still needed by the active project, the canonical
  active copy must live under `../common-info/source-data/`.
- Record any newly rehomed source files in
  `../common-info/ACTIVE_SOURCE_DATA_INDEX.md`.
