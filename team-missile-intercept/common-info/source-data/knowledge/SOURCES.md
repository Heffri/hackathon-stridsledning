# Data Sources & Citation List

> **Source credibility hierarchy** (highest → lowest):
> 1. Official manufacturer manuals / export brochures (PDF)
> 2. Manufacturer official website product pages
> 3. Wikipedia (with cited references)
> 4. Defense analysis / news sites

All specs in this knowledge base are from publicly available, unclassified sources. Values marked `[est]` are community-derived estimates where official data is classified or unavailable.

## Data Confidence Notes

| Data Category | Confidence | Notes |
|---------------|------------|-------|
| Platform dimensions, weight, speed | High | Manufacturer-published |
| Radar detection ranges (Erieye ER) | High | Saab official figures |
| Radar detection ranges (ES-05) | Medium | Some databases cite 222 km, exact classified |
| Missile ranges (Meteor, IRIS-T) | High | MBDA/Diehl published |
| Kill probabilities (Pk) | Low | All estimated — exact values classified |
| RCS values | Medium | Open-source estimates, varies by aspect/frequency |
| Cost figures | Medium | Published procurement data, varies by contract |
| Reload times | Low-Medium | Estimated from training documentation |
