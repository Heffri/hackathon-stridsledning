## Projects

### [`team-missile-intercept/`](team-missile-intercept/) — Team Project

**AI vs AI Missile Interception.** A 3D simulation where Red AI launches missiles/drones and Blue AI selects and guides interceptors in real-time. Physics-based intercept computation, not probability dice rolls.

### [`xingyi-rts/`](xingyi-rts/) — Xingyi's Personal Project

**RTS-style Air Defense Decision Support.** Full IADS simulation with 3-layer response model (EW → evade → hard kill), multi-wave scenarios, and complete Swedish air defense knowledge base.

## Shared Resources

- `saab-provided/` maps and coordinates are in `xingyi-rts/saab-provided/`
- The `xingyi-rts/knowledge/` base contains detailed weapon specs, threat profiles, and engagement doctrine that both projects can reference
